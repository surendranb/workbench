== Description ==

Workbench is an editorial, documentation-dense WordPress block theme built for systems labs, AI studios, and developer portfolios. It provides an ergonomic two-column workstation shell, native Full Site Editing (FSE), and photo-anchored dual-tone color palettes.

Features:
* Full Site Editing (FSE) block theme with theme.json v3.
* Two-column workstation shell with fixed navigation sidebar and responsive mobile layout.
* 6 real-world photo-anchored color palettes (Sunset, Nandi, San Diego, Stanford, Railroad, Permafrost) plus Neelakurunji, Studio Electric, and Terracotta Sun.
* Zero external JavaScript or analytics tracking dependencies.
* Bundled self-hosted variable and character typography (Inter, Newsreader, Geist, Space Grotesk, Bricolage Grotesque).

== Installation ==

1. In your WordPress admin, go to Appearance > Themes and click Add New.
2. Search for "Workbench" or upload the theme zip file.
3. Click Install and then Activate.
4. Navigate to Appearance > Editor to customize templates and styles.

== Frequently Asked Questions ==

= How do I change the color palette? =
Go to Appearance > Editor > Styles to choose between Sunset, Nandi, San Diego, Stanford, Railroad, Permafrost, or classic style variations.

= Does Workbench load external fonts or assets? =
No. All web fonts and palette background assets are self-hosted locally within the theme package. Workbench makes zero external requests and does not track user data.
